# Sistema de Relatórios PFC

Relatórios gerados automaticamente pelo Sistema de Relatórios do Programa Futuro Cientista®

## 🌐 Acesso Online

Acesse: https://programafuturocientista.github.io/overview/

## 📋 Estrutura

- `index.html` - Landing Page principal
- `evasao.html` - Relatório de Evasão
- `assiduidade.html` - Relatório de Assiduidade
- `analises.html` - Análises Avançadas (Machine Learning)
- `auditoria.html` - Sistema de Auditoria
- `olimpiadas.html` - Participação em Olimpíadas
- `cursinho/` - Relatórios do Cursinho Preparatório
- `projeto_vida/` - Sistema de Projeto de Vida

## 🚀 Como Usar

1. Abra `index.html` no navegador
2. Navegue pelos módulos usando o menu
3. Explore os relatórios interativos

## 📊 Dados

Os relatórios são gerados a partir dos dados do Google Sheets do PFC.
