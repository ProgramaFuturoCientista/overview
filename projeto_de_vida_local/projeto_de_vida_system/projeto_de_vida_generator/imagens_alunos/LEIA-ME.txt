🎯 OBJETIVO DESTA PASTA
═══════════════════════════════════════════════════════════════════

    Esta é a pasta PRINCIPAL onde você deve adicionar TODAS as
    imagens que serão usadas nos documentos "Projeto de Vida"
    dos alunos.


📂 ESTRUTURA DE SUBPASTAS
═══════════════════════════════════════════════════════════════════

    imagens_alunos/
    │
    ├── 📸 fotos_perfil/          ← Fotos dos alunos
    │   └── COMO_USAR.txt
    │
    ├── 🖼️ fotos_background/       ← Imagens de fundo (opcional)
    │   └── COMO_USAR.txt
    │
    └── 🎓 logos_universidades/    ← Logos das universidades
        └── COMO_USAR.txt


🚀 INÍCIO RÁPIDO
═══════════════════════════════════════════════════════════════════

    1. Abra a pasta: fotos_perfil/
    2. Leia o arquivo: COMO_USAR.txt
    3. Adicione as fotos dos alunos
    
    4. Abra a pasta: logos_universidades/
    5. Leia o arquivo: COMO_USAR.txt
    6. Adicione os logos das universidades
    
    7. (OPCIONAL) Adicione backgrounds personalizados em:
       fotos_background/


⚠️ IMPORTANTE
═══════════════════════════════════════════════════════════════════

    📝 Leia SEMPRE o arquivo "COMO_USAR.txt" em cada pasta!
    
    Cada pasta tem instruções ESPECÍFICAS e DETALHADAS sobre:
    • Como nomear os arquivos
    • Qual formato usar
    • Qual tamanho ideal
    • Exemplos práticos
