  📸 FOTOS DE PERFIL DOS ALUNOS
  Como adicionar fotos para o Projeto de Vida
═══════════════════════════════════════════════════════════════

🎯 OBJETIVO DESTA PASTA:
   Armazenar as fotos de perfil de cada aluno que aparecerão no
   documento "Projeto de Vida".

📋 COMO ADICIONAR FOTOS:

   1. FORMATO DO NOME DO ARQUIVO:
      • Use o nome COMPLETO do aluno
      • Substitua espaços por underline (_)
      • Use apenas letras, números e underline
      • Extensão: .jpg ou .png
      
      ✅ Exemplos CORRETOS:
         - Joao_da_Silva.jpg
         - Maria_Santos_Oliveira.png
         - Pedro_Henrique_Costa.jpg
      
      ❌ Exemplos INCORRETOS:
         - João da Silva.jpg  (tem espaço e acento)
         - joao.jpg           (sem sobrenome)
         - foto1.jpg          (não identifica o aluno)

   2. ESPECIFICAÇÕES TÉCNICAS:
      • Formato: JPG ou PNG
      • Tamanho recomendado: 500x500 pixels (quadrado)
      • Tamanho máximo: 2MB por imagem
      • Qualidade: Boa resolução, fundo neutro de preferência
      • Foto recente e profissional

   3. DICAS DE QUALIDADE:
      ✓ Use fotos com boa iluminação
      ✓ Fundo neutro ou desfocado
      ✓ Rosto centralizado e visível
      ✓ Sem óculos escuros ou bonés
      ✓ Expressão amigável e profissional

📂 ESTRUTURA DE EXEMPLO:

   imagens_alunos/
   └── fotos_perfil/
       ├── Joao_da_Silva.jpg
       ├── Maria_Santos.jpg
       ├── Pedro_Costa.png
       ├── Ana_Oliveira.jpg
       └── ...

🔄 FUNCIONAMENTO:

   Quando o sistema gerar o Projeto de Vida:
   
   1. Ele procura uma foto com o nome do aluno nesta pasta
   2. Se encontrar, usa essa foto no documento
   3. Se NÃO encontrar, usa uma foto padrão (placeholder)
   
   Exemplo:
   • Aluno: "João da Silva"
   • Sistema procura: "Joao_da_Silva.jpg" ou "Joao_da_Silva.png"
   • Se encontrar: usa a foto do aluno
   • Se não encontrar: usa foto padrão

⚠️ IMPORTANTE:

   • O nome do arquivo deve corresponder EXATAMENTE ao nome
     do aluno no arquivo CSV
   • Remova acentos (á, é, í, ó, ú, ã, õ, ç)
   • Substitua espaços por underline (_)

💡 DICA: Use um script de renomeação para converter nomes
   automaticamente se tiver muitas fotos.
