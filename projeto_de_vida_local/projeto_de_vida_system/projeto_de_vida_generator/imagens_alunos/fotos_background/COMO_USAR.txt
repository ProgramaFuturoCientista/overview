  🖼️ IMAGENS DE FUNDO (BACKGROUND)
  Personalize o fundo do Projeto de Vida
═══════════════════════════════════════════════════════════════

🎯 OBJETIVO DESTA PASTA:
   Armazenar imagens de fundo personalizadas para cada aluno
   (opcional). Se não houver imagem específica, usa a padrão.

📋 COMO ADICIONAR IMAGENS DE FUNDO:

   1. FORMATO DO NOME DO ARQUIVO:
      • Use o nome COMPLETO do aluno + "_bg"
      • Substitua espaços por underline (_)
      • Adicione "_bg" no final (antes da extensão)
      • Extensão: .jpg ou .png
      
      ✅ Exemplos CORRETOS:
         - Joao_da_Silva_bg.jpg
         - Maria_Santos_Oliveira_bg.png
         - Pedro_Henrique_Costa_bg.jpg
      
      ❌ Exemplos INCORRETOS:
         - João_bg.jpg        (tem acento)
         - fundo_joao.jpg     (formato errado)
         - background1.jpg    (não identifica o aluno)

   2. ESPECIFICAÇÕES TÉCNICAS:
      • Formato: JPG ou PNG
      • Tamanho recomendado: 1920x1080 pixels (Full HD)
      • Proporção: 16:9 (paisagem)
      • Tamanho máximo: 5MB por imagem
      • Qualidade: Alta resolução
      • Estilo: Profissional, inspirador, relacionado à educação

   3. SUGESTÕES DE IMAGENS:
      ✓ Campus universitário
      ✓ Biblioteca ou sala de estudos
      ✓ Paisagens inspiradoras
      ✓ Elementos científicos/educacionais
      ✓ Cores suaves (não muito vibrantes)
      ✓ Boa para texto sobreposto (não muito detalhada)

📂 ESTRUTURA DE EXEMPLO:

   imagens_alunos/
   └── fotos_background/
       ├── Joao_da_Silva_bg.jpg
       ├── Maria_Santos_bg.jpg
       ├── Pedro_Costa_bg.png
       └── background_padrao.jpg  ← Imagem padrão (opcional)

🔄 FUNCIONAMENTO:

   Quando o sistema gerar o Projeto de Vida:
   
   1. Procura uma imagem de fundo com o nome do aluno
   2. Se encontrar: usa essa imagem personalizada
   3. Se NÃO encontrar: usa a imagem padrão do template
   
   Exemplo:
   • Aluno: "João da Silva"
   • Sistema procura: "Joao_da_Silva_bg.jpg"
   • Se encontrar: usa background personalizado
   • Se não: usa o background padrão (hero-bg.jpg)

⚙️ IMAGEM PADRÃO (OPCIONAL):

   Você pode criar uma imagem padrão chamada:
   • "background_padrao.jpg"
   
   Esta será usada quando não houver imagem específica
   para um aluno.

⚠️ IMPORTANTE:

   • Imagens de fundo devem ter boa legibilidade
     (texto por cima precisa ser visível)
   • Evite imagens muito escuras ou muito claras
   • Prefira imagens com espaço neutro para texto
   • Teste se o texto fica legível sobre a imagem

💡 DICA: Use filtros de escurecimento ou sobreposição
   semi-transparente para melhorar legibilidade do texto.

🎨 FONTES DE IMAGENS GRATUITAS:

   • Unsplash.com
   • Pexels.com
   • Pixabay.com
   
   Busque por: "university", "education", "study", 
   "graduation", "library", "campus"
